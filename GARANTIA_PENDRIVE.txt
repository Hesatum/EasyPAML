COMPUTADOR DO NOVO USUÁRIO:

Pré-requisito:
  • Python 3.8+ instalado
  • Python com "Add Python to PATH" configurado
  • Windows (7, 8, 10 ou 11)

Processo:
  1. Usuário copia pasta EasyPML do pendrive
  2. Duplo-clique em SETUP.bat
  3. Aguarda conclusão (2-5 minutos)
  4. FECHA TODOS os terminais abertos
  5. ABRE UM NOVO terminal
  6. Duplo-clique em "EasyPML" no Desktop
  7. ✅ PROGRAMA FUNCIONA!

Resultado:
  ✓ Python detectado
  ✓ Dependências instaladas
  ✓ CODEML no PATH
  ✓ Atalho criado
  ✓ Programa abre


O QUE PODE DAR ERRADO (E COMO EVITAR)
───────────────────────────────────────────────────────────────────────────────

❌ "Python não encontrado"
   Causa: Python não instalado ou PATH não configurado
   Solução: Instalar Python com "Add Python to PATH" marcado

❌ "CODEML não encontrado"
   Causa: Usuário não fechou/abriu novo terminal após SETUP
   Solução: FECHAR TODOS os terminais e ABRIR UM NOVO

❌ "Erro de permissão"
   Causa: Sem privilégios de administrador
   Solução: Executar SETUP.bat como Administrador

❌ "Erro ao instalar dependências"
   Causa: Internet lenta ou conexão instável
   Solução: Executar SETUP.bat novamente quando conexão melhorar

❌ "Módulo não encontrado"
   Causa: Dependências não instaladas corretamente
   Solução: Executar install_dependencies.bat manualmente


COMO AJUDAR NOVO USUÁRIO
───────────────────────────────────────────────────────────────────────────────

Se o usuário tiver problema:

1. PRIMEIRO: Verificar Python
   $ python --version
   (Deve mostrar Python 3.8 ou superior)

2. SE não tiver Python:
   → Instalar em https://www.python.org/downloads/
   → MARCAR "Add Python to PATH"

3. SE tiver Python:
   → Executar SETUP.bat novamente
   → Como Administrador se necessário

4. IMPORTANTE: Após SETUP.bat
   → FECHAR todos os terminais
   → ABRIR terminal novo
   → Tente novamente

5. SE ainda não funcionar:
   → Executar: pip install -r requirements.txt
   → Depois: python EasyPAML.py
